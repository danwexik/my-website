# Free Website with GitHub Pages

A modern, responsive personal website and portfolio hosted completely free forever on GitHub Pages.

## 🚀 How to Publish on GitHub in 3 Minutes (No Tools Needed!)

### Step 1: Create a Free GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Enter a **Repository name** (e.g. `my-website` or `<your-username>.github.io`).
3. Make sure **Public** is selected.
4. Check the box **"Add a README file"**.
5. Click **Create repository**.

### Step 2: Upload Website Files
1. Inside your new GitHub repository, click **Add file** &gt; **Upload files**.
2. Drag and drop these files from your computer:
   - `index.html`
   - `style.css`
   - `script.js`
3. Click the green button: **Commit changes**.

### Step 3: Turn On Free GitHub Pages Hosting
1. In your repository, click **Settings** (gear icon near top right).
2. On the left sidebar menu, click **Pages**.
3. Under **Build and deployment** &gt; **Branch**:
   - Change `None` to `main`.
   - Leave folder as `/(root)`.
   - Click **Save**.

🎉 **You are done!** In about 1 minute, GitHub will give you a live URL:
`https://<your-username>.github.io/<repository-name>`
